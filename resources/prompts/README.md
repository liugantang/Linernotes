# Prompt 模板系统说明

本目录存放 Linernotes 内置的 Prompt 模板文件。

## 目录与命名结构

- 文件路径：`resources/prompts/<功能>/<名称>.md`
- 模板 ID：`<功能>/<名称>`（例如 `common/ping`、`cleanup/normalize`）
- 模板 ID 仅允许由小写字母、数字、下划线及连字符组成，且必须符合 `<功能>/<名称>` 结构（正则：`^[a-z0-9_-]+/[a-z0-9_-]+$`）。

## 模板文件格式

Prompt 模板使用包含 YAML Frontmatter 头部与分段正文的 Markdown 文件格式：

```markdown
---
version: 1
description: 一句话说明该模板用途
---
=== system ===
系统提示词（可选）

=== user ===
用户提示词（必填），支持变量：{{title}} 或 {{ title }}
```

- **头部（Frontmatter）**：位于文件起始处的两个 `---` 分隔行之间，每行采用 `key: value` 格式。
  - `version`（必填）：正整数，表示模板版本号。
  - `description`（可选）：一句话描述该模板的功能与用途。
  - 其他未识别的键会被自动忽略。
- **正文分段**：
  - `=== system ===`：系统角色提示词段落（可选）。
  - `=== user ===`：用户角色提示词段落（必填）。
  - 各段落内容会自动去除首尾空白行，保留段落内部换行。
- **变量插值**：
  - 变量采用 `{{name}}` 占位符，变量名匹配 `[A-Za-z_][A-Za-z0-9_]*`。
  - 大括号内部允许包含前后空格，如 `{{ name }}`。
  - 渲染模板时若缺失必填变量，将返回 `kPromptInvalid` 错误并列出所有缺失的变量名；多传入的变量将被忽略。
  - 变量值原样插入，不会进行二次展开（变量值中若含有 `{{x}}` 会保持原样）。
- **文件编码**：所有文件均使用 UTF-8 编码读取。

## 用户覆盖与版本管理机制

- **内置资源**：编译进程序的默认模板位于 Qt 资源路径 `:/prompts/`。
- **用户覆盖**：用户可在应用配置目录下的 `prompts/` 目录（即 `<配置目录>/prompts/<功能>/<名称>.md`）放置同名模板文件进行覆盖自定义。
- **查找优先级**：从高到低依次查找（用户配置目录优先于内置资源目录）。
- **版本号规则**：
  - 当修改内置模板的提示词逻辑或增减变量时，必须将 `version` 版本号递增（+1）。
  - 当用户覆盖文件的版本号低于内置模板版本号时，系统会在日志中发出 `qCWarning(lcAi)` 警告提示覆盖文件已过时，但仍会继续使用用户的文件。
