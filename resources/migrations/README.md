# 数据库迁移脚本编写约定

1. **命名规范**：文件命名为 `NNNN_<描述>.sql`，例如 `0001_init.sql`、`0002_add_lyrics.sql`。编号必须为 4 位数字且从 `0001` 开始连续递增，不得有空缺或重复。
2. **不可修改性**：已合并入 `main` 分支的迁移脚本绝对不得修改。如有结构变更需新增下一个编号的迁移脚本。
3. **事务控制**：迁移框架在执行每个迁移脚本前后会自动开启和提交事务（`BEGIN IMMEDIATE` / `COMMIT`）。脚本内**不得**编写 `BEGIN`、`COMMIT`、`ROLLBACK` 等事务控制语句。
4. **外键约束**：脚本内**不得**编写 `PRAGMA foreign_keys`，因为 SQLite 中该 PRAGMA 在事务内部是无效的。框架在迁移完成后会自动执行 `PRAGMA foreign_key_check` 进行外键完整性校验。
